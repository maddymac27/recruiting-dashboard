| Boundary | Description |
|----------|-------------|
| client form → Server Action | Contact/conversation input (incl. pasted free-text) crosses into the mutation tier |
| pasted notes → persisted → re-rendered timeline | Free-text (self-forwarded LinkedIn) round-trips through storage into HTML |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-16 | Tampering / Elevation of Privilege | pasted conversation notes persisted then rendered in the timeline | high | mitigate | Notes persisted verbatim but rendered only as escaped JSX text nodes (02-04 timeline); the form uses no raw-HTML injection prop. Primary stored-XSS control for the free-text paste path. |
| T-02-17 | Tampering | logContactAction / logConversationAction input | medium | mitigate | Both actions `safeParse` against the Phase 1 newContactInput/newConversationInput Zod schemas before any Drizzle write (ASVS V5). |
| T-02-18 | Information Disclosure | client form importing server-only db | medium | mitigate | Form receives applicationId/companyId as props and mutates only via Server Actions; it never imports `@/db/client` (enforced by the Task 2 negative grep). |
</threat_model>
