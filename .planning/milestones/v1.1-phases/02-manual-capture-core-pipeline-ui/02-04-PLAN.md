## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-09 | Tampering / Elevation of Privilege | conversation notes rendered in timeline.tsx | high | mitigate | Notes render only as escaped JSX text nodes; no raw-HTML injection prop is used (enforced by the Task 2 negative grep). This is the primary stored-XSS control for the phase. |
| T-02-10 | Tampering | `id` route param → Number() lookup | low | mitigate | id is coerced with Number() and used only as a parameterized Drizzle `.where(eq(...))` value; a non-numeric/oob id resolves to no row → notFound(), never raw SQL. |
| T-02-11 | Information Disclosure | detail read hitting wrong store | low | accept | Single `db` client resolves demo/real once (Phase 1 D-13); no per-request switch. |
</threat_model>
