<objective>
Scaffold Tailwind CSS v4 + shadcn/ui from scratch and stand up the persistent app shell (nav + DEMO badge) that every later Phase 2 slice renders inside. This is the shared UI foundation: no CSS framework, `components.json`, or shell chrome exists yet — only the Phase 1 liveness `layout.tsx`.

## Phase Goal (user story, derived from ROADMAP Phase 2 goal + success criteria)

**As an** active job-seeker running my search, **I want to** open a portfolio-grade dashboard shell that clearly shows whether I'm looking at demo or real data and lets me navigate to my pipeline, **so that** every capture/board/detail slice built on top has a consistent, screen-shareable home and I can never confuse invented demo data with my real search.

Purpose: Establishes the styling system (D2-01/03) and app shell (D2-02) and the demo-mode signal (D2-04) that Wave 2/3 slices depend on. Delivers a visible outcome (navigable shell + DEMO badge), not a divorced "styling layer."

</objective>
