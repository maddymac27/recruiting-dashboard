## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing |
| md | 16px | Default element spacing |
| lg | 24px | Section padding |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions: 44px minimum hit target for icon-only interactive controls (the stage-change trigger button, contact/conversation row action icons) — required by D2-06's "mobile-safe" stage-change interaction even though the app is desktop-first this phase.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Label | 14px | 400 | 1.5 |
| Body | 16px | 400 | 1.5 |
| Heading | 20px | 600 | 1.2 |
| Display | 28px | 600 | 1.2 |

- Label (14px/400): KPI row labels, timeline timestamps, form field labels, table meta text.
- Body (16px/400): card body text, dialog form values, timeline entry text, conversation notes.
- Heading (20px/600): card titles, dialog titles, board column headers, section headings on the detail view.
- Display (28px/600): page title ("Pipeline"), KPI count numerals.

Exactly 2 weights declared (400 regular, 600 semibold) — no additional weights permitted this phase.

| error | Quick-save dialog, Full add/edit dialog, Contact/conversation form (form) | ✅ covered | Confirmed: "Couldn't save this change. Check the fields below and try again." (see Copywriting Contract) |

| partial | Full add/edit dialog, edit mode with null underlying fields (form) | 🧪 backstop | A field with no stored value renders as empty/placeholder, never as literal "null"/"undefined" text |
| overflow | Pipeline board columns (list-collection) | 🧪 backstop | Each column scrolls independently vertically when card count exceeds visible height; cards never truncate |
| overflow | Job detail timeline (list-collection) | 🧪 backstop | Timeline scrolls vertically at any length; no pagination in this phase |
| overflow | Nav shell (nav) | ✅ covered | Fixed short labels ("Pipeline", "Today", "Analytics") at every viewport — no overflow risk |

| long-text | Quick-save / Full add/edit dialogs — company name, role title (form) | 🧪 backstop | Long values truncate with ellipsis in display contexts (board cards, KPI row); full value remains visible in the form input and via a title/tooltip attribute |
| long-text | Job detail timeline — pasted LinkedIn notes / conversation text (static-content) | 🧪 backstop | Full text wraps in the timeline entry with no truncation or character limit — capture fidelity matters more than compact layout for this element |
| long-text | Stage-change control — stage labels from the lookup table (interactive-control) | 🧪 backstop | Stage name labels wrap inside the select/dropdown if unusually long; control is not fixed-width-clipped, so future stage additions (extensible per Phase 1 D-07) don't break the UI |
| long-text | Nav shell, DEMO badge (nav, static-content) | ✅ covered | Both render fixed, code-authored short strings ("Pipeline"/"Today"/"Analytics", "DEMO") — never dynamic length |
