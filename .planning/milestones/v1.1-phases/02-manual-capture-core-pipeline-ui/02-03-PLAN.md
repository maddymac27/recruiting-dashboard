<objective>
Deliver the first user-visible slice: a pipeline board that shows where every application stands, grouped into stage columns read from the lookup vocabulary, with a KPI summary row above it. This is a read-only slice — cards link to the (Wave 2) detail route; the add/quick-save/change-stage writes are the Wave 3 slice built on top of this page.

## Phase Goal (user story, derived from ROADMAP Phase 2 goal + success criteria)

**As an** active job-seeker, **I want to** open one board and see every application in its current stage with at-a-glance counts (applied / saved-not-applied / in progress / closed), **so that** I know the state of my whole search without hunting through a spreadsheet.

Purpose: Closes DASH-02 (pipeline view) and DASH-04 (summary counts) on demo/seed data. After this task, a real user can view their whole pipeline — something they could not do before.
Output: `board.ts` + `lookups.ts` read models, the board page + four server components, and `board.test.ts`.
</objective>
