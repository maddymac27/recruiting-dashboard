<objective>
Build the Gmail read pipeline and the first per-sender parser, all unit-tested against an injected mock (no live network in tests). `src/gmail/query.ts` builds the targeted `from:` OR query + `after:` filter (ING-02) and resolves the "Job Search" label id (ING-03, fail-loud); `src/gmail/fetch.ts` paginates `messages.list` and turns `format=raw` into clean text via base64url → mailparser → html-to-text; `src/gmail/parsers/handshake.ts` + `index.ts` extract company + status + real event date (D3-05) and dispatch by From domain (ING-04, Handshake). Uses the CONFIRMED domains/label from 03-03's sampling; parser regex is authored against the synthetic fixtures captured there.

Purpose: This is the I/O + extraction plumbing the orchestrator (03-05) composes into an end-to-end sync. Isolating it behind a `GmailClient` interface makes the orchestrator testable without live Gmail.

ASSUMPTION (surface explicitly): per-sender templates are LOW confidence (D3-02) — the Handshake regex is written against sampled synthetic fixtures and MUST be re-validated by the live sync smoke test in 03-05; do not treat it as verified against all employers' Handshake customizations.
