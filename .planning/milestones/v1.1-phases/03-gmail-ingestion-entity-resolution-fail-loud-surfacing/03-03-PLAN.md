## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser ↔ Google OAuth | Consent + code exchange; redirect_uri must match exactly |
| server ↔ .secrets/ | Long-lived refresh token at rest, server-only |
| server ↔ client bundle | Token/OAuth code must never cross to the client |
| demo mode ↔ real Gmail | Demo must never reach the real account/token |
