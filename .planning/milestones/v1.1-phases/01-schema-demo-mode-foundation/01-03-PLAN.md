<objective>
Implement the event-sourcing core: create an application capturing all analysis dimensions, append status changes as append-only dated events with message-ID idempotency, and derive current stage from events ordered by real-world time.

Purpose: This is the un-retrofittable heart of the schema (D-09/D-10, DATA-01/02/03/06). The out-of-order derivation and message-ID idempotency are exactly the two failure modes every prior tracker attempt died on, so they get dedicated tests here.
Output: Three domain modules (applications, events, projections) with tests proving append-only storage, correct out-of-order derivation, and idempotent inserts.
</objective>
