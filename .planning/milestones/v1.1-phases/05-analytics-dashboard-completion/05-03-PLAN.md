## Phase Goal

**As a** job seeker, **I want to** see summary counts and a funnel of how far my applications have progressed, **so that** I can tell what's actually converting across my whole search.

_(Derived from ROADMAP Phase 5 goal + DASH-06 success criterion — not invented.)_

<objective>
Deliver the `/analytics` view (DASH-06): a summary-metrics row plus a simple funnel bar chart computed over the append-only status-event history. Adopts the D5-07 default (basic recharts funnel + minimal summary metrics; all-time range; no date slicing).

Purpose: answers the second Phase 5 question — "what's working" — using data that has accumulated since Phase 1, deliberately kept BASIC to avoid ANLYT-01/02/03 richer-analytics creep (deferred to v2).
Output: a new analytics domain module, a client funnel chart, and the `/analytics` page.

No schema changes occur (every count is read from the existing statusEvents/applications/stages tables). Aggregation is done in TypeScript, never via SQL GROUP BY (RESEARCH Pattern 3 — drizzle-orm is pinned at 1.0.0-rc.4 and this codebase has zero group-by queries).
</objective>
