## Phase Goal

**As a** job seeker, **I want to** see gone-quiet applications flagged on the pipeline board too, **so that** the staleness signal is visible wherever I look, not just on the Today view.

_(Derived from DASH-03 + UI-SPEC Surface 3 — not invented.)_

<objective>
Add the gone-quiet overlay badge to the pipeline board cards (UI-SPEC Surface 3, the board half of DASH-03). Reuses the exact shared predicate and D5-01 clock built in plan 05-01 — this plan adds no new staleness logic, only threads the pre-computed staleness through the board component tree and renders the badge on the card.

Purpose: DASH-03's auto-flag should be visible on the board (where the user manages applications), not only on the Today view — the whole point of the shared D5-08 module is one predicate feeding both surfaces.
Output: the board card renders a "Gone quiet · {N} days" Destructive badge for flagged, non-terminal applications.

No schema changes occur. No new domain or predicate code is written — this plan is pure UI wiring over 05-01's `getStalenessByApplication`.
</objective>
