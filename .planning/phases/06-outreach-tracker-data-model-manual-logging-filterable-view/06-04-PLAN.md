## Phase Goal

**As a** job seeker running an active search, **I want to** open an "Outreach" tab that lists every message I've logged and lets me filter and sort by company, channel, recency, and response, **so that** I can see which messaging converts.

**This plan (06-04) integrates the slice into a live tab:** the /outreach route + filterable/sortable table + nav link, wiring in the log form (06-03) as the page CTA and the view dialog (06-03) as the row action. After it, the full manual-outreach loop — log, list, filter/sort, read, see-what-converted — works end-to-end.

Output: src/app/outreach/page.tsx, src/app/outreach/loading.tsx, src/components/outreach-table.tsx, src/components/nav-shell.tsx (nav entry).
</objective>
